# AGENTS.md

Guía para agentes de código (Codex, Cursor, Gemini CLI, etc.). El contenido completo vive en
[`CLAUDE.md`](./CLAUDE.md): léelo antes de trabajar. Hay un único origen a propósito, para que las dos guías no se desfasen.

Lo mínimo:

1. Lee [`CONTEXT.md`](./CONTEXT.md) antes de tocar cualquier cosa del dominio y no inventes datos de Nexova.
2. Pon cada cosa en su carpeta (ver "Arquitectura" en `CLAUDE.md`); no tires código en la raíz.
3. Cada app, servicio, agente o pipeline nuevo lleva subcarpeta y README.
